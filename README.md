# מחשבון סדר משיכות אופטימלי

אפליקציית Web סטטית בעברית להשוואת סדר משיכות ממוצרים פיננסיים. המחשבון מעריך מס מיידי, עלות ויתור על מעטפת מס, ומקצה צורך נטו בין מוצרים לפי דירוג תכנוני, מס מיידי בלבד או סדר ידני.

## הפעלה מקומית

נדרש Node.js 20 ומעלה לבדיקות. אין תלויות ואין שלב build.

```bash
npm test
npx serve .
```

לאחר מכן פותחים את הכתובת שמציג `serve`. אפשר להשתמש גם בכל שרת קבצים סטטי אחר. פתיחה ישירה של `index.html` עלולה להיחסם בדפדפנים מסוימים בגלל JavaScript modules.

## פרטיות ומגבלות

כל החישובים והנתונים נשארים בדפדפן. טיוטה, הגדרות מס ותרחישים נשמרים ב־`localStorage`; לא נשלח מידע לשירות חיצוני. אין להזין מידע אישי רגיש במחשב שאינו פרטי. זהו מודל תכנוני פשוט: הוא אינו מחשב מס ריאלי, מדד, קיזוז הפסדים, תקרות, פטורים אישיים או תנאי מוצר מלאים, ואינו ייעוץ.

## שינוי הנחות המס

בטבלה „מאפייני מס והנחות” אפשר לערוך אחוזים וטקסטים. השינויים נשמרים אוטומטית בדפדפן ומשמשים כברירת מחדל. override בכרטיס מוצר גובר על הטבלה; ניקויו מחזיר לברירת המחדל. ברירות המחדל בקוד נמצאות ב־`PRODUCT_TYPES` בקובץ `js/calculations.js`.

## GitHub ו־GitHub Pages

1. יוצרים repository ומעלים אליו את כל הקבצים (`git add .`, `git commit`, `git push`).
2. ב־GitHub נכנסים אל **Settings → Pages**.
3. תחת **Build and deployment → Source** בוחרים **GitHub Actions**.
4. כל push לענף `main` או `master` מריץ בדיקות ומפרסם דרך `.github/workflows/pages.yml`.

כל הנתיבים יחסיים, ולכן האתר עובד גם תחת `https://USER.github.io/REPOSITORY/` ללא שינוי שם repository או base path. לחלופין אפשר לבחור פרסום ישיר מהענף ומהתיקייה `/ (root)`.

## מבנה

- `index.html` — הממשק.
- `css/styles.css` — עיצוב RTL, מובייל והדפסה.
- `js/calculations.js` — פונקציות טהורות לחישוב, דירוג והקצאה.
- `js/app.js` — ממשק, שמירה, תרחישים וייצוא.
- `tests/` — בדיקות אוטומטיות עם Node test runner.
